03 / READ THE LABEL

Provenance before performance

01

Public is reproducible

The repository publishes synthetic suite definitions, fixtures, schemas, harness code, checks, and aggregate reference metadata. You can inspect the test and run it.

02

Historical is contextual

Retained evidence can be published without rerunning, but it remains attached to its original harness and conditions. It does not become an APB public-suite score by proximity.

03

Scores are not universal rankings

Sampling, budgets, quantization, hardware, adapters, scoring treatment, timeouts, and exclusions matter. Results describe measurements under stated conditions.

What this page does not claim

  • No reproduction of, exact parity with, or endorsement by Agent Max 2 or DFlash.
  • No invented per-model breakdowns beyond the supplied verified facts.
  • No equivalence between deterministic fixture-mode smoke tests and generative model scores.
  • No controlled throughput comparison across unlike systems or workloads.
